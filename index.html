Đồng Bộ Google Drive (Offline-First)

Dữ liệu được lưu trữ trực tiếp trên Google Drive của chính bạn (không qua bất kỳ máy chủ trung gian nào). Mỗi thiết bị đều có thể dùng chung dữ liệu.

* Xem hướng dẫn tạo Google Client ID miễn phí trong file README hoặc tài liệu đính kèm.

Xuất Dữ Liệu Ra File CSV (Excel)

Xuất file CSV chuẩn định dạng UTF-8 có BOM (mở trực tiếp bằng Microsoft Excel không bị lỗi font tiếng Việt).

Sao Lưu & Khôi Phục Dự Phòng (JSON)

Tải toàn bộ cơ sở dữ liệu về máy hoặc khôi phục từ tệp đã sao lưu trước đó. Hỗ trợ đặt mật khẩu mã hóa AES-GCM.
